ตั้งค่า Supabase ก่อนเริ่มใช้งาน

แก้ค่า SB_URL และ SB_PUBLISHABLE_KEY ที่ส่วน CONFIG ในไฟล์ index.html

const SB_URL = 'https://YOUR_PROJECT.supabase.co';
const SB_PUBLISHABLE_KEY = 'YOUR_PUBLISHABLE_OR_ANON_KEY';
const dbClient = window.supabase.createClient(SB_URL, SB_PUBLISHABLE_KEY);

ใช้เฉพาะ Publishable key หรือ anon key ใน Browser ห้ามใช้ service_role key
